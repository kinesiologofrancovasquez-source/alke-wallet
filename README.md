# Alke Wallet

Proyecto final desarrollado para el módulo de JavaScript.

## Descripción

Alke Wallet es una aplicación web que simula una billetera digital, permitiendo al usuario gestionar sus fondos, realizar depósitos, retiros y transferencias, además de consultar sus movimientos.

El proyecto fue desarrollado utilizando HTML, CSS y JavaScript, incorporando almacenamiento local para mantener la información de la billetera durante la navegación.

## Tecnologías utilizadas

- HTML5
- CSS3
- JavaScript
- Bootstrap
- jQuery
- LocalStorage
- Git
- GitHub

## Funcionalidades

- Inicio de sesión de usuario.
- Visualización del saldo disponible.
- Depósito de dinero.
- Retiro de dinero.
- Envío de dinero a contactos.
- Gestión de contactos.
- Historial de movimientos.
- Actualización automática del saldo.
- Persistencia de datos mediante LocalStorage.
- Validación de formularios.
- Interfaz responsive.
